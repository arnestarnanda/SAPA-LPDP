# Gemma Hackathon – Cloud Next Extended: Participant Guide

## Introduction
Welcome to the Gemma Hackathon at Cloud Next Extended! You will have three hours to build a working project in a two-person team using Gemma through the organiser-provided Gemini Enterprise Agent platform. Build something useful, creative and demonstrable with Antigravity.

## Quick Overview
* **Team size:** 2 participants
* **Submission window:** 30 minutes allotted at the end of the build session
* **Total duration for building:** 3 hours
* **Optional showcase:** 30 minutes after submissions
* **Required submissions:** Kaggle Project Write-up and Labtracer
* **Cash prizes:** 1st ($900/team), 2nd ($600/team), 3rd ($500/team) place
* **Swag:** Top 10 teams
* **Showcase (Voluntary):** 2 minutes pitch (1 slide) + live working demo

## Schedule / Agenda
* **12:40 - 13:10 (0:30):** Vibecoding & Integrating your Apps with Gemma through Agent Platform
* **13:10 - 15:40 (2:30):** Build Session
* **15:40 - 16:10 (0:30):** Build Session - Submission
* **16:10 - 16:40 (0:30):** Showcase and Storytelling
* **16:40 - 17:15 (0:35):** Behind the Bill: What We’re Actually Paying in AI Infrastructure Costs
* **17:15 - 17:25 (0:10):** Awarding Session

## What You Can Build
You may build any project idea, provided that Gemma is meaningful and central to the solution. A focused, reliable prototype is better than a broad but incomplete one.

## Provided Tools and Accounts
* Gemma access will be provided through temporary Gemini Enterprise Agent accounts for the event day.
* **Gemma model to be used on Model Garden:** `publishers/google/models/gemma-4-26b-a4b-it-maas`
* You do not need to host your own Gemma model.
* Antigravity must be used as part of your development workflow.
* Do not share credentials or publish private workspace URLs, account details or other sensitive information.
* Capture your demo video and supporting evidence.

## Project Requirements
* Gemma must perform a meaningful function in the main user experience.
* Your core user flow must be demonstrable or verifiable.
* Use Google Cloud products only where they make sense within the architecture.
* Provide a public repository or Kaggle Notebook that supports technical verification.
* Disclose external APIs, datasets, templates, AI tools and pre-existing code used.

## Submission Requirements
Each team must complete both submissions before the deadline:
1. **Kaggle Project Write-up** (Official competition submission & winner record)
   * Project name, Team members, Problem statement, Proposed solution.
   * Gemma integration details.
   * Agentic development workflow (Antigravity use, Skills/MCP integrations).
   * Google Cloud architecture.
   * Functionality and known limitations.
   * Project links (Repo/Kaggle notebook, optional deployed app, public YouTube demo).
   * Instructions to run/test.

2. **Labtracer Submission**
   * Project name.
   * Public YouTube demo (<= 3 mins, screen recording showing user flow & Gemma behavior).
   * Public Medium or Dev.to blog post (can reuse Kaggle content; explains problem, solution, architecture, Gemma, Antigravity workflow, Skills/MCP, GCP products).

## Judging Criteria (Total: 100 points)
1. **Gemma Integration — 20 points**
   * Gemma's importance to the solution (8 pts)
   * Agent workflow & integration quality (7 pts)
   * Prompting & output handling (5 pts)
2. **Innovation and Impact — 20 points**
   * Problem clarity & relevance (7 pts)
   * Originality (7 pts)
   * Potential user value & viability (6 pts)
3. **Functionality — 20 points**
   * Core flow works (10 pts)
   * Output quality & reliability (5 pts)
   * Usability & prototype completeness (5 pts)
4. **Agentic Developer Tools Utilisation — 15 points**
   * Effective use of Antigravity (9 pts)
   * Depth & impact of agentic workflow (3 pts)
   * Evidence & explanation in blog (3 pts)
5. **Google Cloud Product Utilisation — 15 points**
   * Appropriateness of selected products (6 pts)
   * Coherence & practicality of architecture (6 pts)
   * Implementation / credible integration evidence (3 pts)
6. **Submission Quality and Communication — 10 points**
   * Problem, solution, architecture clarity (3 pts)
   * Repo, config, testing instructions (2 pts)
   * Demo video (2 pts)
   * Blog documentation (3 pts)

## Submission Eligibility Checklist
* Kaggle & Labtracer submitted before deadline.
* YouTube demo public & <= 3 minutes.
* Blog (Medium/Dev.to) public.
* Gemma used via Gemini Enterprise Agent platform (`publishers/google/models/gemma-4-26b-a4b-it-maas`).
* Public repo / Kaggle notebook.
* Demonstrable core functionality.
